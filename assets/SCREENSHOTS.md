# Screenshot capture requirements

No application screenshot or test-result image is included. The draft screenshot placeholder was removed for publication; the architecture SVG is a sanitized logical illustration.

A suitable future capture shows a synthetic question, its answer and one supporting synthetic passage. Crop browser chrome, account menus, sidebars, access routes, chat identifiers, model-provider prefixes and unrelated conversations. Use a dedicated fictional corpus rather than blurring a production screenshot. Inspect the full image and metadata before adding it. Caption the date, configuration scope and whether the capture is a real run or an illustration. Never caption a mockup as acceptance evidence.
